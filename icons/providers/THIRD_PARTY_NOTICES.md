# Provider logo assets

The SVG files in this directory were retrieved from the public
[models.dev](https://models.dev/) provider logo catalog on 2026-07-12.
The catalog source is available at
[sst/models.dev](https://github.com/sst/models.dev) under the MIT license.

Provider names and logos may also be trademarks of their respective owners.
They are bundled by Voryel only to identify the provider selected by the user;
their inclusion does not imply endorsement, sponsorship, or affiliation.

`catalog.json` contains only the public provider ID, display name, and API base
URL required for local icon matching. It contains no credentials or user data.
